# The Hollow Games: WebGL playtest build

A Unity 6 WebGL build of *The Hollow Games* (Okiki Popoola and Ebube Eze, COSC 332),
hosted for playtesting with [Playtest Room](https://github.com/ebub323/playtest-room).

This repo holds only the built game. Textures are capped at 512 px for the web build.
