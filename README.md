# The Hollow Games: WebGL playtest build

A Unity 6 WebGL build of *The Hollow Games* (Okiki Popoola and Ebube Eze),
hosted for playtesting with [Playtest Room](https://github.com/ebub323/playtest-room).

This repo holds only the built game. Gzip-compressed with textures capped at 256 px so it loads quickly on GitHub Pages.
